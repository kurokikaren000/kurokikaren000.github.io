黒跪カレン OFFICIAL WEBSITE — GitHub Pages 公開手順

■ 内容
index.html / style.css / script.js / assets/hero.webp / assets/ogp.webp / assets/favicon.png
追加のサーバー設定や有料サービスは不要です。

■ 既存サイトをリニューアルする方法
1. まず GitHub の既存リポジトリを ZIP でバックアップしておくことを推奨します。
   https://github.com/kurokikaren000/kurokikaren000.github.io
2. この ZIP を解凍し、中の「index.html」「style.css」「script.js」「assets」フォルダを確認します。
3. リポジトリの「Add file」→「Upload files」を選びます。
4. ファイルと assets フォルダをまとめてアップロードし、コミットします。
   同名ファイルの上書きとなる場合は、変更内容を確認してください。
5. main ブランチの GitHub Pages (root) から自動公開されます。
   公開URLは従来の https://kurokikaren000.github.io/ のままです。

■ 反映されないとき
Ctrl + Shift + R でハードリロード、またはスマホのプライベートブラウズで確認。

■ カスタマイズ
- トップ写真：assets/hero.webp を差し替え
- SNS等のリンク・文章：index.html
- 配色とデザイン：style.css
- サイトの動作：script.js
- SNSシェア画像：assets/ogp.webp
